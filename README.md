## Personal Portfolio / Resume — Vue 3 SPA

[Live site](https://dannycode.site/about)

A data-driven single-page portfolio built to showcase software engineering experience.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | [Vue 3](https://vuejs.org/) (Composition API) |
| Build tool | [Vite 6](https://vitejs.dev/) |
| State management | [Pinia](https://pinia.vuejs.org/) (Composition store setup) |
| Routing | [Vue Router 4](https://router.vuejs.org/) |
| Styling | [Bootstrap 5](https://getbootstrap.com/) + [SASS](https://sass-lang.com/) |
| Icons | [Font Awesome 6](https://fontawesome.com/) + [PrimeIcons](https://primereact.org/icons/) |
| Analytics | [Vercel Analytics](https://vercel.com/analytics) |
| Linting | ESLint 9 + eslint-plugin-vue |
| Deployment | [Vercel](https://vercel.com/)  |
